# company-knowledge

Company-specific knowledge repository for AI OS.

**Contents:**
- `knowledge/company/` — Company identity, profile, hub
- `knowledge/clients/` — Client registry and profiles
- `knowledge/projects/` — All project bounded contexts
- `manifest/` — Company Manifest layer
- `plugins/` — Company-specific tool plugins

**Lifecycle:** Living document. Updated as projects evolve.

**Relation to ai-os-core:** This repository provides company-specific knowledge. Capabilities, skills, playbooks, templates, and frameworks live in `ai-os-core`.
