# Reports Hub

Ringkasan status dan riwayat pelaporan per project, dikelompokkan di
`knowledge/projects/<project>/reports/`.

Laporan final (versi yang dikirim) disimpan di `outputs/reports/`; folder ini
menyimpan konteks pendukung dan riwayat singkat status lintas waktu.

## Per Project

_(Tambahkan link ke subfolder report per project saat project dibuat)_

- `knowledge/projects/<project-slug>/reports/` → lihat [[{{project-slug}}/project-profile]]

## Alur Kerja

Lihat `playbooks/status-report-playbook.md` dan
`skills/project-status-report/SKILL.md`.
