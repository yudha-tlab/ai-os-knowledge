# Layanan

Main Works mendukung fungsi Project Manager di Teknologi Kode Indonesia (TLAB)
di enam area kerja:

1. **Project Management** — project charter, RAID log, status report, prioritisasi lintas project.
2. **Business Analysis** — requirement gathering, BRD, process mapping, user story.
3. **System Analysis** — FRD, SRS, requirement traceability matrix, catatan arsitektur.
4. **Meeting Management** — agenda, notulen (MOM), tindak lanjut action item.
5. **Stakeholder Management & Reporting** — executive briefing, presentasi steering committee, komunikasi risiko.
6. **Dokumentasi & Presentasi Umum** — proposal, spreadsheet analysis, test plan, generasi dokumen dari template.

Semua layanan ini diakses melalui workflow Telegram-first — lihat
[[main-works-daily-operating-system-v1]] untuk daftar lengkap perintah.
