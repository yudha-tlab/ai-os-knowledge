# Presentations Hub

Materi presentasi (steering committee, status review) per project, dikelompokkan
di `knowledge/projects/<project>/presentations/`.

Deck final disimpan di `outputs/presentations/`; folder ini menyimpan konteks
dan riwayat presentasi sebelumnya untuk referensi.

## Per Project

_(Tambahkan link ke subfolder presentation per project saat dibutuhkan)_

- `knowledge/projects/<project-slug>/presentations/` → lihat [[{{project-slug}}/project-profile]]

## Alur Kerja

Lihat `playbooks/presentation-playbook.md` dan
`skills/presentation-design/SKILL.md`.
