# Requirements Hub

Requirement list yang tervalidasi (business, functional, non-functional) untuk
semua project, dikelompokkan per project di
`knowledge/projects/<project>/requirements/`.

BRD/FRD/SRS final disimpan di `outputs/brd/`, `outputs/frd/`, `outputs/srs/`;
folder ini menyimpan working requirement list dan traceability sebelum
menjadi dokumen formal.

## Per Project

_(Tambahkan link ke subfolder requirement per project saat project dibuat)_

- `knowledge/projects/<project-slug>/requirements/` → lihat [[{{project-slug}}/project-profile]]

## Alur Kerja

Lihat `playbooks/requirement-analysis-playbook.md`,
`playbooks/business-analysis-playbook.md`, dan
`playbooks/system-analysis-playbook.md`.
