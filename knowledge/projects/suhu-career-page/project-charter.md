# Project Charter: Suhu - Career Page

## 1. Project Overview

- **Project Name**: Suhu - Career Page
- **Client**: suhu.co.id (TLab Group)
- **Project Manager**: Yudha Pratama
- **Start Date**: 2026-07-10
- **Target Date**: TBD
- **Methodology**: Agile

## 2. Project Vision

Membuat halaman Career Page di website Suhu.co.id untuk memungkinkan pencarian kerja dan perekrutan kandidat secara mandiri oleh tim HR/klien.

## 3. Project Scope

### 3.1 In Scope

* Halaman Career Listing (daftar lowongan)
* Sistem input data career (admin/backend)
* Form aplikasi kandidat
* Integrasi dengan website Suhu.co.id yang ada

### 3.2 Out of Scope

* ATS (Applicant Tracking System) komprehensif
* Integrasi dengan platform perekrutan eksternal (LinkedIn, dll) — menunggu konfirmasi
* Mobile app khusus — menunggu konfirmasi

## 4. Success Criteria

* Halaman Career Page live di suhu.co.id
* Admin dapat input lowongan tanpa bantuan teknis
* Kandidat dapat submit aplikasi via form
