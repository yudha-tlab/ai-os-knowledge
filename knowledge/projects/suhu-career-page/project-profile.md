## 1. Overview

Pengembangan halaman Career Page untuk website Suhu.co.id (TLab Group). Saat ini website belum memiliki halaman karir. Project ini akan membuat:
- Halaman daftar lowongan kerja (Career Listing)
- Sistem input data career yang sedang dibuka
- Form aplikasi untuk kandidat yang tertarik
- Backend/admin interface untuk mengelola lowongan

Requirement gathering akan dimulai pada meeting besok (2026-07-10 jam 09:00).
