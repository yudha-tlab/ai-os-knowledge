# Project Charter — SIMWASKRA

**Tanggal Dibuat:** 2026-10-20
**Project Manager:** Yudha Pratama
**Client/Divisi:** Inspektorat Kabupaten Karanganyar
**Status:** Draft

## 1. Latar Belakang & Tujuan

Inspektorat Kabupaten Karanganyar menjalankan proses pengawasan daerah melalui
aplikasi SIMWASKRA. Sistem ini mendukung pengelolaan kegiatan pengawasan,
pemantauan progres, pendokumentasian hasil, pemantauan tindak lanjut temuan, dan
penyusunan laporan.

Sistem sudah berjalan. Klien menginginkan penyesuaian terhadap sistem tersebut.
Lingkup penyesuaian belum didefinisikan dan menjadi fokus penggalian requirement
pada tahap berikutnya.
