## Ringkasan Project

Penetrasi Testing VMWare untuk BPD Sumut — assessment kerentanan infrastruktur virtualisasi server (VMware) menggunakan VM appliance berisi Nuclei dan OpenVAS. Pendekatan **blackbox**: tidak ada akses kredensial ke sistem target, pengujian dari perspektif penyerang tanpa akses internal. TLab bertindak sebagai subkontraktor Lintasarta (kontraktor utama BPD Sumut).
