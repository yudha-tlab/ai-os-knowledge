# Riwayat Perubahan BRD — CRM Multi-Tenant TLab

File ini memisahkan **riwayat proses penyusunan** dari dokumen BRD. BRD
(`bootcamp-crm-brd-v1.md`) sengaja dijaga bersih dari catatan proses karena
dipakai sebagai **bahan presentasi tim pada hari 1 bootcamp**; jejak perubahannya
disimpan di sini agar traceability tidak hilang.
