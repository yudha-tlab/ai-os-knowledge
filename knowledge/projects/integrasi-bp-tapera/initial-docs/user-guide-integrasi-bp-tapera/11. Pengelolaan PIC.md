### 1. Menambahkan PIC baru ke dalam sistem BP Tapera

---

| Field | Value |
|---|---|
| User Story | Sebagai Admin Bank Sumsel Babel, saya ingin menambahkan Person In Charge (PIC) baru ke dalam sistem BP Tapera agar dapat mendaftarkan PIC yang akan bertanggung jawab atas pengajuan kredit dan pengelolaan hubungan antara Bank Sumsel Babel dan BP Tapera |
| Reference Document | Tambah PIC |
| Test Case Description | Memastikan user dapat menambahkan PIC baru ke dalam sistem BP Tapera |
| Pre-Conditi on | 1. User login sebagai Admin 2. User berada pada halaman Person in Charge (PIC) |
| Post-Condit ion | 1. Berhasil menambahkan PIC baru 2. Data PIC baru berhasil disimpan ke sistem BP Tapera 3. Menampilkan informasi bahwa berhasil menambahkan data PIC |
