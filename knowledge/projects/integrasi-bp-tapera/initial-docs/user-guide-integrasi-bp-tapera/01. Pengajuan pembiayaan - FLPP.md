Sebagai Operator Cabang, saya ingin mengajukan pembiayaan melalui sistem agar dapat memproses permohonan pengajuan pembiayaan program FLPP [Pengajuan Pembiayaan](https://kiwitcms.tlab.co.id/case/2275/)

2. User berada di halaman form pengajuan pembiayaan untuk program FLPP
3. User berstatus menikah
1. Pengajuan berhasil dibuat
2. Sistem menampilkan informasi pengajuan berhasil dikirim
