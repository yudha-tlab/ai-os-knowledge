### 1. Melakukan pengajuan prioritas pembiayaan

---

| Field | Value |
|---|---|
| User Story | Sebagai Petugas Bank Sumsel Babel, saya ingin mengajukan prioritas pembiayaan ke BP Tapera agar dapat memproses pengajuan nasabah dengan efisien |
| Reference Document | Pengajuan Prioritas |
| Test Case Description | Memastikan user dapat melakukan pengajuan prioritas pembiayaan |
| Pre-Condition | 1. User login sebagai Petugas Bank 2. User berada pada halaman Pengajuan Prioritas |
| Post-Conditio n | 1. Pengajuan prioritas berhasil dikirim ke BP Tapera 2. Data pengajuan tersimpan ke dalam sistem 3. Menampilkan informasi bahwa pengajuan berhsail dilakukan |
