Test Case Memastikan user dapat melakukan pengajuan efek terkait pembiayaan Description

---

Pre-Conditio 1. User login sebagai Petugas Bank n

2. User memiliki informasi efek yang siap diajukan
3. User berada pada form Tambah Efek

---

Post-Conditi 1. Berhasil melakukann pengajuan efek on

2. Data efek disimpan dalam sistem
3. Menampilkan informasi bahwa pengtajuan efek berhasil dilakukan

| No | Test Step |
|---|---|
| 1 | Verifikasi Nomor Batch |
| 3 | Input Tenor |
| 4 | Input Nilai Efek |
| 5 | Input Bunga |
| 6 | Input Jumlah Kali Bayar |
| 7 | Pilih Jenis Efek |
| 8 | Pilih Skema Porsi Dana |
| 9 | Input Nilai Pencairan |
| 10 | Input Nilai Pencairan Dipercepat |
| 11 | Klik tombol "Ajukan Efek" |
