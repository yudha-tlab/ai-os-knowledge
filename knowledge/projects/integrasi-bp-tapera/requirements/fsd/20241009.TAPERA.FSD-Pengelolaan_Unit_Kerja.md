1. # Pengelolaan Unit Kerja

User Story : Sebagai superadmin saya ingin mengelola cabang/unit kerja, agar saya dapat melihat, menambah, mengubah dan menonaktifkan data cabang

1. ## Tambah Unit Kerja

   1. ### Purpose/Description

Fitur ini digunakan untuk menambahkan unit kerja ke dalam sistem, agar masing-masing unit kerja dapat mengelola data kredit pembiayaan dari BP tapera.

2. ### Use Case

| UC-1 | Tambah Unit Kerja |
| :---- | :---- |
| **Primary Actor(s)** | Superadmin Bank Sumsel Babel |
| **Stakeholders and Interest** | Bank Sumsel Babel, BP Tapera |
| **Trigger** | Superadmin klik tombol "Tambah Unit Kerja" di aplikasi |
| **Pre-conditions** | Superadmin sudah login ke sistem  |
| **Post-conditions** | Unit kerja berhasil ditambahkan ke sistem BSB Tapera. |
| **Main Success Scenario** | 1\. Superadmin memilih opsi "Tambah Unit Kerja" 2\. Sistem menampilkan form tambah unit kerja 3\. Superadmin mengisi data unit kerja yang diperlukan 4\. Superadmin submit data unit kerja 5\. Sistem memvalidasi data 6\. Sistem mengirim data ke BSB Tapera 7\. Sistem menampilkan konfirmasi penambahan unit kerja berhasil |
| **Extensions** | 5a. Jika validasi gagal, sistem menampilkan pesan error dan kembali ke langkah 3 |
| **Priority** | High |
| **Special Requirements** |  |

   3. ### Mock-up

      4. ### Functional Requirement

| Spec ID | Specification Description | Business Rules/ Data Dependency |
| :---- | :---- | :---- |
| FR-1 | Sistem harus menampilkan daftar cabang dengan kategori cabang pusat dan kantor cabang | Cabang Induk wajib diisi jika kategori cabang yang dipilih cabang pembantu atau kantor kas |
| FR-2 | Sistem harus menampilkan konfirmasi setelah unit kerja berhasil ditambahkan | Konfirmasi harus menampilkan nama unit kerja dan keterangan sukses |

2. ## List Unit Kerja

   1. ### Purpose/Description

Fitur ini digunakan untuk melihat daftar unit kerja yang terdaftar dalam sistem,tujuannya adalah untuk memfasilitasi pengelolaan data unit kerja.

2. ### Use Case

| UC-2 | List Unit Kerja |
| :---- | :---- |
| **Primary Actor(s)** | Superadmin Bank Sumsel Babel |
| **Stakeholders and Interest** | Bank Sumsel Babel, BP Tapera |
| **Trigger** | Superadmin memilih menu "Data Unit Kerja" di aplikasi |
| **Pre-conditions** | Superadmin sudah login ke sistem  |
| **Post-conditions** | Daftar Unit kerja ditampilkan kepada superadmin. |
| **Main Success Scenario** | 1\. Superadmin memilih menu "Data Unit Kerja" 2\. Sistem menampilkan data unit kerja 3\. Superadmin melihat informasi data unit kerja |
| **Extensions** | 2a. Jika data unit kerja masih kosong, sistem menampilkan informasi bahwa tidak ada data yang ditampilkan |
| **Priority** | High |
| **Special Requirements** | Terdapat fitur pagination Terdapat fitur pencarian data Terdapat fitur filter data  |
