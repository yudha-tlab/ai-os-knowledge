1. # Pengelolaan User & PIC

User Story : Sebagai superadmin saya ingin mengelola user dan pic, agar user dan pic dapat terdaftar di sistem BSB dan BP Tapera

1. ## Tambah User PIC

   1. ### Purpose/Description

Fitur ini digunakan untuk menambahkan user dan pic ke dalam sistem, agar masing-masing user dapat mengelola data kredit pembiayaan dari BP tapera.

2. ### Use Case

| UC-1 | Tambah User PIC |
| :---- | :---- |
| **Primary Actor(s)** | Superadmin Bank Sumsel Babel |
| **Stakeholders and Interest** | Bank Sumsel Babel, BP Tapera |
| **Trigger** | Superadmin klik tombol "Tambah user" di aplikasi |
| **Pre-conditions** | Superadmin sudah login ke sistem  |
| **Post-conditions** | User berhasil ditambahkan ke sistem BSB Tapera. |
| **Main Success Scenario** | 1\. Superadmin memilih opsi "Tambah User" 2\. Sistem menampilkan form tambah user 3\. Superadmin mengisi data user yang diperlukan 4\. Superadmin submit data user 5\. Sistem memvalidasi data 6\. Sistem mengirim data ke API BP Tapera 7\. Sistem mengirim data ke BSB Tapera 8\. Sistem menampilkan konfirmasi penambahan user berhasil |
| **Extensions** | 5a. Jika validasi gagal, sistem menampilkan pesan error dan kembali ke langkah 3 6a. Jika sistem gagal mengirim data ke API BP Tapera, sistem menampilkan pesan error dan kembali ke langkah 4 |
| **Priority** | High |
| **Special Requirements** |  |

   3. ### Mock-up

      4. ### Functional Requirement

| Spec ID | Specification Description | Business Rules/ Data Dependency |
| :---- | :---- | :---- |
| FR-1 | Sistem harus memvalidasi format email, NIK, dan nomor HP | Email harus valid, NIK harus 16 digit, nomor HP harus valid |
| FR-2 | Sistem harus mengenkripsi NIK sebelum pengiriman | Data NIK harus di enkripsi end-to-end |
| FR-3 | Sistem harus mengintegrasikan dengan API BP Tapera untuk pengiriman data PIC | \- |
| FR-4 | Sistem harus memungkinkan penambahan multiple cabang untuk mengakomodir kebutuhan BP Tapera untuk mengcover beberapa lokasi perumahan | \- |
| FR-5 | Sistem harus menampilkan konfirmasi setelah user berhasil ditambahkan | Konfirmasi harus menampilkan keterangan sukses |

2. ## List User PIC

   1. ### Purpose/Description

2. ### Use Case

| UC-2 | List User PIC |
| :---- | :---- |
| **Primary Actor(s)** | Superadmin Bank Sumsel Babel |
| **Stakeholders and Interest** | Bank Sumsel Babel, BP Tapera |
| **Trigger** | Superadmin memilih menu "Data User" di aplikasi |
| **Pre-conditions** | Superadmin sudah login ke sistem |
| **Post-conditions** | Data User ditampilkan kepada superadmin. |
| **Main Success Scenario** | 1\. Superadmin memilih menu "Data User" 2\. Sistem menampilkan data user 3\. Superadmin melihat informasi data user |
