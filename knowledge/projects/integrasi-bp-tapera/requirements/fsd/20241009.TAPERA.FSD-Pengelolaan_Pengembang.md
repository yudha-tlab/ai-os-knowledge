1. # Pengelolaan Pengambang

User Story : Sebagai operator cabang saya ingin mengelola data Pengembang Perumahan, agar data pengembang dapat digunakan untuk mengisi data akad

1. ## Tambah Data Pengembang

   1. ### Purpose/Description

Fitur ini digunakan untuk menambahkan data pengembang ke dalam sistem, agar memudahkan input data pada saat proses akad.

2. ### Use Case

| UC-1 | Tambah Unit Kerja |
| :---- | :---- |
| **Primary Actor(s)** | Operator Cabang Bank Sumsel Babel |
| **Stakeholders and Interest** | Bank Sumsel Babel, BP Tapera |
| **Trigger** | Superadmin klik tombol "Tambah Data Pengembang" di aplikasi |
| **Pre-conditions** | Superadmin sudah login ke sistem  |
| **Post-conditions** | Data Pengembang berhasil ditambahkan ke sistem BSB Tapera. |
| **Main Success Scenario** | 1\. Superadmin memilih opsi "Tambah Data pengembang" 2\. Sistem menampilkan form tambah data pengembang 3\. Superadmin mengisi data pengembang yang diperlukan 4\. Superadmin submit data pengembang 5\. Sistem memvalidasi data 6\. Sistem mengirim data ke BSB 7\. Sistem menampilkan konfirmasi penambahan data pengembang berhasil |
| **Extensions** | 5a. Jika validasi gagal, sistem menampilkan pesan error dan kembali ke langkah 3 |
| **Priority** | High |
| **Special Requirements** |  |

   3. ### Mock-up

      4. ### Functional Requirement

| FR-2 | Sistem harus menampilkan konfirmasi setelah pengembang berhasil ditambahkan | Konfirmasi harus menampilkan nama pengembang dan keterangan sukses |

2. ## List Pengembang

   1. ### Purpose/Description

Fitur ini digunakan untuk melihat daftar data pengembang masing-masing cabang yang terdaftar dalam sistem,tujuannya adalah untuk memfasilitasi pengelolaan data pengembang.

| **Pre-conditions** | Superadmin sudah login ke sistem  |
| **Post-conditions** | Daftar Pengembang ditampilkan kepada operator. |
| **Main Success Scenario** | 1\. Superadmin memilih menu "Data Pengembang" 2\. Sistem menampilkan data pengembang 3\. Superadmin melihat informasi data pengembang |
